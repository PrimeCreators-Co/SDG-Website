# 🌍 Smart Health & Innovation Hub

**Smart Health & Innovation Hub** is a **multi-page responsive website** designed to promote healthy living through interactive tools and showcase how innovation can transform healthcare and infrastructure.  

This project directly supports:  
- **SDG 3: Good Health and Well-being**  
- **SDG 9: Industry, Innovation, and Infrastructure**

## 🎯 Project Objectives
1. Educate users about **preventive healthcare** and lifestyle improvements.  
2. Provide **interactive health tools** that encourage awareness and self-care.  
3. Highlight the role of **innovation and infrastructure** in advancing healthcare.  
4. Demonstrate the **responsible use of AI tools** to build creative, impactful projects.  

## ✨ Features
### Core Pages
- **Home Page** – A detailed landing page that introduces the project, explains its SDG impact, and guides users to explore further.  
- **About Page** – Information about the project’s goals, documentation, and contribution to SDGs.  
- **Health Tools Page** – Interactive web tools (BMI calculator, water intake tracker, health quiz).  
- **Innovation Page** – Displays real-world examples of innovative healthcare solutions.  
- **Resources Page** – Articles, tips, and external resources on SDG 3 & 9.  
- **Contact Page** – A working contact form for feedback.  

### Global Features
- Responsive **Navbar** and **Footer** across all pages.  
- Clean, modern **UI/UX design** with pastel/green/blue health-tech vibes.  
- JavaScript-powered interactivity (calculators, form validation, quiz).  
- Fully **mobile-friendly** layout.  
- Optional **AI integration** (e.g., AI-generated health tips).  

## 🏠 Home Page (Detailed Overview)
The **Home Page** is the **heart of the project** — it creates the first impression for users and sets the tone for the rest of the website. It is designed to be visually appealing, informative, and highly engaging.  

### Sections of the Home Page:
1. **Navbar (Sticky)**  
   - Positioned at the top, visible on all pages.  
   - Contains links to: Home, About, Tools, Innovation, Resources, Contact.  
   - Mobile-friendly menu toggle for smaller screens.  

2. **Hero Section (Big Visual Banner)**  
   - Full-screen background image (health/innovation theme).  
   - Title: **“Empowering Health through Innovation”**  
   - Subtitle: Explains connection to **SDG 3 & 9**.  
   - Call-to-Action (CTA) Button: *“Learn More”* linking to the About page.  

3. **SDG Highlight Section**  
   - Icons of **SDG 3 (Good Health)** and **SDG 9 (Innovation & Infrastructure)**.  
   - Brief description of how this project contributes to both.  
   - Example: “Preventive healthcare awareness + digital innovation = sustainable impact.”  

4. **Quick Stats Section**  
   - Animated counters showing impactful facts, e.g.:
     - “70% of diseases are preventable with lifestyle awareness.”  
     - “4.5 billion people still lack access to essential healthcare.”  
     - “Digital health can reduce costs by 30% worldwide.”  

5. **Preview of Health Tools**  
   - Small card previews of tools (BMI Calculator, Water Tracker, Quiz).  
   - Each card links to the full **Health Tools Page**.  

6. **Innovation Spotlight**  
   - Carousel or grid with 2–3 highlights (e.g., AI diagnosis, wearable tech, smart hospitals).  
   - CTA: *“Explore More on Innovation Page”*.  

7. **Testimonials / Quotes Section** (Optional)  
   - Short motivational quotes about health and innovation.  
   - Example: *“Health is the greatest wealth — sustainable innovation makes it accessible to all.”*  

8. **Footer Preview (Mini)**  
   - Quick links + “Supporting SDG 3 & 9” statement.  

### Purpose of Home Page
- Serve as the **introduction and hub** for navigation.  
- **Engage users immediately** with visuals, facts, and CTAs.  
- Educate users right away about the project’s relevance to **SDG goals**.  
- Encourage exploration of the other pages (About, Tools, Innovation, etc.).

## ⚡ Minimum Viable Product (MVP)
The **MVP version** of this project must include:  
- A **multi-page website** with responsive **navbar & footer**.  
- Fully functional **Home Page** with hero, SDG highlights, and navigation.  
- **At least 1 working health tool (BMI Calculator)** on the Tools page.  
- **About Page** with problem, solution, and impact explanation.  
- **Contact Page** with form validation.  

Everything beyond MVP (extra tools, AI chatbot, graphs, animations) adds bonus marks.

## 🚀 Setup Instructions
1. Clone or download the repository.  
2. Open the folder in **Visual Studio Code**.  
3. Install the **Live Server** extension in VS Code (recommended).  
4. Right-click `index.html` → **Open with Live Server**.  
5. Navigate the website through the navbar.  

## 🧪 Usage Guide
- Visit **Home Page** → Learn about the project and SDG 3 & 9.  
- Go to **Tools Page** → Try the BMI Calculator and other health tools.  
- Explore **Innovation Page** → See real-world smart health solutions.  
- Browse **Resources Page** → Read health tips and SDG material.  
- Use **Contact Page** → Submit a feedback form.
